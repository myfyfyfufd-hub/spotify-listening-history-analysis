# Spotify Listening History Analysis

## Project Overview

This repository contains a Spotify listening history dataset with 149,860 streaming records covering the period from July 2013 to December 2024.

The dataset provides information about listening activity, including track names, artists, albums, streaming platforms, playback duration, and user listening behavior.

The purpose of this project is to provide a dataset for exploring music listening patterns and performing real-world data analytics.

## Dataset Information

| Property | Details |
|---|---|
| Dataset | Spotify Listening History |
| Total Records | 149,860 |
| Time Period | July 2013 – December 2024 |
| Total Columns | 11 |
| Format | CSV |
| Data Source | Personal Spotify Listening History |

## Files Included

- `spotify_history.csv` – Main dataset containing Spotify listening records.
- `spotify_data_dictionary Description.csv` – Data dictionary explaining the dataset fields.

## Dataset Columns

| Column | Description |
|---|---|
| spotify_track_uri | Unique Spotify track identifier |
| ts | Timestamp when playback stopped (UTC) |
| platform | Streaming platform |
| ms_played | Playback duration in milliseconds |
| track_name | Name of the track |
| artist_name | Artist name |
| album_name | Album name |
| reason_start | Reason playback started |
| reason_end | Reason playback ended |
| shuffle | Whether shuffle mode was enabled |
| skipped | Whether the track was skipped |

## Potential Data Analysis

This dataset can be used to explore:

- Most frequently played artists.
- Most frequently played tracks.
- Total listening time.
- Monthly and yearly listening trends.
- Listening behavior across different platforms.
- Skipped tracks and playback patterns.
- Shuffle versus non-shuffle listening behavior.
- Music listening trends over time.
